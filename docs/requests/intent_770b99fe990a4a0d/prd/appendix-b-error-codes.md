# 附录 B：错误码表

> 规则：每条错误必须有「现象 → 原因 → 下一步」三段中文，且 `next_action` 必须是可点击的动作，不能只写"请联系支持"。
> 12 条标 ★ 的是验收必测集合（G2），其余为运行中必然出现的扩展错误。
> 错误对象结构：`{code, severity, message_zh, cause_zh, next_action{label,deep_link}, detail, retriable, context}`。

## B.1 错误严重级

| 级别 | 语义 | UI 表现 |
| --- | --- | --- |
| `blocking` | 当前步骤无法继续 | 红色横幅 + 主按钮"去修复" |
| `recoverable` | 已自动处理或可一键重试 | 黄色提示 + "查看详情" |
| `warning` | 可继续但有风险 | 灰色/黄色行内提示 |
| `fatal` | 应用级故障 | 全屏错误页 + 诊断包导出 |

## B.2 错误聚合与降噪

- 同一任务内同码错误只弹一次 toast，其余折叠到"共 N 条"。
- 批量任务（如 20 条音频）中 `SVC-3001/6004` 走列表聚合，不逐条弹窗。
- 同一错误码在 24h 内出现 ≥3 次，任务中心顶部出现"常见问题"卡片，附一键修复。
