> 因此模板的「Tailwind CSS-style styling constraints」「class length」「Vue component extraction」三节按 **React 口径**落地：
> 样式唯一来源 = Tailwind utilities + `src/lib/theme.css` 的 CSS 变量 token；"class" = Tailwind 类名串（超长必须拆成 `cva` 变体或组件，不许拼模板字符串）；"Vue 组件" = React 函数组件（props / 回调 / 受控状态）。
> 渲染进程**没有文件与进程权限**，所有数据经 Rust command / Channel 取得；页面不得自行读盘或推算任务状态。

## 1. 页面目标

一个桌面控制台要同时成立三件事：

1. **知道现在在哪**：任何时候打开都能看出"卡在哪一步、下一步点哪里"（对应 PRD §6 P1 的 7 步流水线卡）。
2. **敢按下去**：长任务（训练/推理）前有冒烟与参数推荐，按下去之前就知道大概会发生什么。
3. **坏了能修**：错误是"现象→原因→下一步"，而不是一行英文堆栈（PRD §8.2、附录 B）。

页面不为"好看"服务，为**降低误操作与降低放弃率**服务。

## 2. 目标用户与场景

| 用户 | 场景 | 页面设计含义 |
| --- | --- | --- |
| U1 个人创作者（6GB 卡、不懂参数） | S-A 首次训练；S-C 调效果 | 默认值必须能直接跑；参数分组折叠；每个推荐值给"为什么"；长任务先冒烟 |

## 5. 用户旅程与任务成功

### 5.1 首次训练（J1→J6，U1）

| 阶段 | 页面 | 用户动作 | 成功信号 | 失败恢复 |
| --- | --- | --- | --- | --- |
| 进入 | P1 | 新建项目（名称/说话人/编码器/素材类型） | 项目创建后 7 步卡显示第 1 步"可开始" | 路径不可写 → 就地提示换目录 |
| 自检 | P8→P1 | 看 doctor 结果 | 9 项全绿，训练按钮可用 | 失败项 → "去修复"跳到资产/设置 |
| 导数据 | P2 | 拖入文件夹 | 文件列表出现 + QC 自动跑 | 结构非法 → 逐条问题列表 |
| 过门禁 | P2 | 处理阻断项 | 横幅变绿"可以预处理" | 阻断未清 → 预处理按钮置灰 + 悬停原因 |
| 预处理 | P3 | 点"开始预处理" | 三步进度 + 计数差异 0 | 差异 >0 → 差异清单 + 单条重跑 |
| 训练 | P4 | 点"冒烟" | 100 步完成，4 项检查打勾 | OOM → 自动降档并提示；NaN → 停止 + 数据诊断 |
| 长训 | P4 | 点"开始训练" | 曲线在动、step 在涨 | 停止 → 显示"停在第 N 步，可续训" |
| 试听 | P5 | 选模型→拖音频→推理 | 播放器出波形，A/B 可切 | 失败 → 错误卡 + 参数建议 |

**主操作**：每页只有一个实心主按钮（下一步）。
**次操作**：查看日志、复制命令、打开目录（文字按钮）。
**危险操作**：删除项目/模型、清理 checkpoint、覆盖配置 —— 全部二次确认，默认焦点在"取消"。

### 5.2 外部模型试听（U2 / 拿到别人的模型）

```
P6 上传区拖入（模型+config）
  ├─ 缺件 → 弹窗「请上传模型和配置文件」→ 留在原地，0 字节
  └─ 完整 → 复制 → 识别
        ├─ 通过 → 模型卡出现 → 点"试听" → P5（模型已选中）
        └─ 失败 → 弹窗「无法识别该模型」→ 详情看缺失键
P5 → 选音频 → 参数默认 → 推理 → 输出落 imports/<模型>/outputs/<批次>/
```
成功信号：模型卡出现且状态 `ready`；推理后批次目录里同时有音频与 `report.json`。

### 5.3 入口与出口

- 应用启动 → 有最近项目则直接进 P1；无项目 → P1 空态（新建/导入项目两个入口）。
- 任务完成 → 托盘通知 + P1 最近任务刷新；点击通知回到对应页面。
- 退出 → 默认最小化到托盘（可在 P8 改为询问/直接退出）。

## 6. 信息架构与内容策略

### 6.1 导航分组

```
① 项目（P1，落地页）
② 数据集（P2）      ③ 预处理（P3）     ④ 训练（P4）
⑤ 推理（P5）        ⑥ 模型库（P6）     ⑦ 任务（P7）
────────────────────────────
⑧ 设置（P8，底部）  关于/合规（P8 内）
```
左侧 240px；分组用 8px 间距与 1px 分隔线，不用嵌套菜单——8 项一屏可见，避免二级导航。

### 6.2 阅读顺序（每页统一）

`页面标题 + 状态徽标` → `阻断/警告横幅（如有）` → `主内容` → `主按钮固定在右下`。
先给结论（能不能继续），再给细节（参数/日志），最后给动作。

### 6.3 渐进披露

- 参数：常用 6 个直接显示；其余折叠进"高级参数（N）"。
- 日志：默认显示尾部 200 行，向上滚动加载更多；不默认展开全文。
- 模型卡：网格只显示名称/步数/状态/体积；编码器、指纹、兼容性进右侧抽屉。

## 9. 视觉方向

- **调性**：工具型控制台（compact console），不是消费级 App。信息密度中高，装饰最少，边框 1px、圆角 6px、阴影几乎不用（仅浮层/抽屉用 8px 模糊）。
- **间距节奏**：4 的倍数；区块 24、卡片内 16、行内 8。
- **表面**：内容区用背景色，卡片用 surface + 1px border；不使用大面积渐变或插画。
- **图标**：线性 16px，统一 1.5px 描边；状态图标与文案同时出现。
- **空态**：一句话 + 一个主按钮 + 一条"为什么"说明；不用插画占位（桌面工具里插画反而增加噪音）。
- **动效**：仅进度条与抽屉 150ms ease-out；不做页面转场动画（避免"卡"的错觉）。

## 11. 样式方向与约束（Tailwind + CSS 变量）

- **唯一来源**：`src/lib/theme.css` 定义 token（`--bg / --surface / --fg / --muted / --accent / --danger / --warn / --ok / --radius / --gap`），Tailwind 配置把这些映射为语义色名（`bg-surface`、`text-muted`、`border-danger`）。
- **写法**：只用 Tailwind utilities，类名按"布局 → 间距 → 排版 → 颜色 → 状态"顺序；同一元素的类名超过约 120 字符或出现 3 个以上条件分支时，必须用 `cva` 定义变体，不允许拼接模板字符串生成类名。
- **禁止**：`style={{...}}` 承载颜色/间距（仅允许动态数值，如进度条 `width`、波形 canvas 尺寸）；组件内写死十六进制色；引入第二套 UI 主题系统（MUI/Ant 全量）。
- **状态表达**：`data-state="idle|running|ok|warn|error|disabled"` + Tailwind `data-[state=error]:*` 变体，状态值域与 PRD 一致，不新增。
- **主题**：浅/深两套 token，`prefers-color-scheme` + 用户覆盖（`<html data-theme>`）；切换即时生效，不改组件代码。
- **数字对齐**：`font-variant-numeric: tabular-nums`（步数/时长/体积/显存），避免表格数字跳动。
- **图标**：内联 SVG 组件（`currentColor` 跟随文字色），不引图标字体。
- **密度**：表格行 36px、卡片内边距 16px、页面边距 24px；这三项写进 token，不许逐页微调。

## 12. 交互骨架

| 交互 | 规则 |
| --- | --- |
| 主按钮 | 每页 1 个，sticky 右下 64px 条；禁用时必须给出原因（悬停 tooltip + 条内一行文字） |
| 拖拽 | 数据集区、上传区、推理音频区接受拖拽；拖入高亮 2px 强调边框；松开即执行（上传区先做完整性检查） |
| 长任务 | 启动后按钮变"停止/取消"，进度区接管；页面可自由切换，任务在后台继续 |
| 停止/取消 | 停止 = 优雅退出（可续训）；取消 = 立即终止。两者都需在 5s 内进程树退出（PRD §7.3） |
| 删除 | 二次确认 + 输入名称（项目）/ 显示占用任务（模型）；默认焦点"取消" |
| 关闭窗口 | 默认最小化到托盘；设置可改"询问"或"退出并停止任务" |
| 错误卡 | 标题=现象，正文=原因，右下 1–2 个动作（"去修复"/"重试"/"复制详情"） |
| 表单校验 | 失焦即校验；错误就地显示在字段下方，不用 toast 报字段错 |
| 键盘 | Tab 顺序 = 视觉顺序；Esc 关闭抽屉/取消弹窗；Enter 触发主按钮（弹窗内除外） |

**交互优先级**：主按钮 > 页头次级动作（文字）> 行内动作（图标按钮）> 折叠区动作 > 危险动作（红字，永远不与主按钮相邻）。

## 14. 文案与反馈基调

- **语气**：陈述事实，不卖萌、不道歉过度。禁止"哎呀""出错了呢"。
- **三段式**：`现象（发生了什么）` → `原因（为什么）` → `下一步（点哪里）`。
- **诚实**：暂停=停止；丢步就说丢步；CPU 推理慢就说 RTF 与"不可训练"。
- **禁用原因**：按钮旁一行小字 > tooltip 兜底（触屏/键盘用户看不到 tooltip）。
- **破坏性确认**：标题写动作与对象（"删除模型 小满@2400？"），正文写后果（"批次输出不会被删除"），按钮用动词（"删除"）而非"确定"。
- **文案授权**：具体措辞由 spec 定稿（`PRD-§8` 规则授权），本阶段只定结构与语气，不新增产品承诺。

## 16. 可访问性

- **键盘**：全部功能可 Tab 到达；抽屉/弹窗打开时焦点移入，Esc 关闭后焦点回到触发控件（PRD §12 无障碍要求）。
- **焦点可见**：2px 强调色外描边，任何主题下对比度 ≥3:1。
- **对比度**：正文 ≥4.5:1，大字号 ≥3:1；错误红与背景 ≥4.5:1。
- **不只靠颜色**：状态 = 图标 + 文案 + 颜色三通道；色盲模拟下仍可区分（用形状：✓ / ! / × / ●）。
- **屏幕阅读器**：图标按钮必须有 `aria-label`；进度条用 `role="progressbar"` + `aria-valuenow/aria-valuetext`（"训练 62%，step 1240"）；动态日志区 `aria-live="polite"` 且只在阶段变化时播报，不逐行播报。
- **动效**：尊重"减少动画"（系统设置），关闭脉冲/进度动画，仅保留数值更新。
- **命中区域**：可点击控件 ≥32×32；表格行内图标按钮 28×28 但整格可点。

## 17. 可用性与风险控制

| 风险 | 缓解 |
| --- | --- |
| 7 步卡让用户误以为"必须全绿才能用" | 卡片标注"可跳过"的步骤（如扩散/聚类可选）；阻断与建议用不同颜色与文案 |
| 参数太多导致放弃 | 默认只显示 6 个；"为什么"用 ⓘ；高级区默认折叠但记住展开状态 |
| 长任务黑箱焦虑 | 曲线 + step + ETA + 显存四件套常驻；训练中可安全切页 |
| 误删模型 | 占用检查 + 输入名称确认 + 批次输出不受影响 |
| 上传区误拖 1.5GB 文件 | 先做完整性检查（<1s），缺件直接弹窗，0 字节写入 |
| 批量推理中一条坏文件毁掉整批 | 逐条隔离 + 失败清单 + 仅重跑失败 |
| 中文路径在老组件里出问题 | 状态栏显示真实工作路径；出错时错误卡附完整路径可复制 |

## 18. 组件复用与抽取策略（React）

> 规则：有 ≥2 个真实调用方，或存在单调用方的明确边界理由（内聚业务区块 / 交互生命周期 / 可测面），才抽取。
> 单调用方"只是因为页面太长"**不构成**抽取理由；props 透传组件（只把 DTO 传下去）一律不抽。

| 候选 | 调用方 | 决定 | 理由与契约 |
| --- | --- | --- | --- |
| `StatusPill` | P1/P2/P4/P5/P6/P7（6 处） | **抽取** | 状态→色/图标/文案映射只允许一处；props：`state, text`；无回调 |
| `JobLogView` | P4/P5/P7（3 处） | **抽取** | 日志节流、过滤、搜索、导出是同一套行为；props：`jobId, source`；回调：`onOpenReport` |
| `PipelineBar` | P1 顶部 + 全局标题栏（2 处） | **抽取** | 7 步状态机与跳转逻辑唯一；props：`steps, current`；回调：`onStepClick` |
| `DropZone` | P2/P5/P6（3 处） | **抽取** | 拖拽/点击/校验回调一致；props：`accept, hint, enabled`；回调：`onDrop(paths)` |
| `ErrorCard` | 全局（错误统一组件） | **抽取** | 三段式结构强制统一；props：`code, cause, actions` |
| `ConfirmDialog` | 删除项目/模型/清理 | **抽取** | 危险操作措辞与焦点规则统一；props：`title, body, confirmText, requireText` |
| `ABPlayer` | 仅 P5 | **抽取（单调用方例外：交互生命周期）** | 双轨同步、LUFS 对齐、波形缩放是一段独立生命周期（`AudioContext` 生命周期 + canvas 渲染），内联会让 P5 变成 800 行；独立后可单测同步逻辑 |
| `QcGauge` | 仅 P2 | **抽取（单调用方例外：可测面）** | 阈值判定（≤20% / <0.1%）是纯函数，抽出来配单测；UI 很薄 |
| `LossChart` | 仅 P4 | **抽取（单调用方例外：渲染隔离）** | canvas 绘制与 React 渲染解耦，避免每个 metric 事件触发组件树更新 |
| 训练参数表单 | 仅 P4 | **不抽取** | 参数与 P4 强绑定，抽成通用 `ParamForm` 会变成宽 props + 业务语义泄漏 |
| 预处理命令预览 | 仅 P3 | **不抽取** | 一次性只读文本块 + 复制按钮，抽出即 pass-through |
| 模型卡网格 | 仅 P6 | **不抽取** | 卡片内容随来源（训练/外部）不同语义，抽通用卡会引入 `mode` 分支 |
| 页面页头 | 8 处但形态不同 | **不抽取** | 标题/徽标/动作差异大；用统一的 `PageHeader` 容器（布局）而非通用业务组件 |

**组件边界与样式**：组件内部只用语义 token 类（`text-danger`），不接受外部传颜色；需要主题差异时用 `data-state` 变体；组件不直接 `invoke`（除页面级容器），数据由页面注入，便于用 mock 测试。

## 19. 设计风险

1. **7 步卡过度承诺**：卡片是"产线状态"不是"必须完成的清单"，若文案不清会被理解为强制流程 → 每张卡副标题写"可跳过/建议"。
2. **三栏在 1366×768 笔记本上挤压** → 断点提前到 1280，参数改抽屉；发布前必须在 1366×768 实机走查。
3. **日志与曲线同屏争空间** → Tab 切换而非上下堆叠；记住上次 Tab。
4. **上传区常驻占空间** → 折叠为 148px 高；模型多时自动收到页头"导入"按钮（不删功能，只降权重）。
5. **深色主题下错误红刺眼** → 错误色降饱和（#F87171 系），背景仅 4% 透明叠加。
